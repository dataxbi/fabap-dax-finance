
# Fabric Apps - DAX Finance

Una aplicación de Fabric creada con la plantilla Data App de Rayfin y que se conecta a un modelo semántico de finanzas.

La implementación actual se centra en un informe PyG con datos reales:

- Tres tarjetas resumen en la parte superior
- Una única tabla jerárquica construida con [TanStack Table](https://tanstack.com/table/latest)
- Sin uso del datagrid original de la plantilla Data App
- Sin gráficos Vega-Lite en runtime
