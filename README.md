
# Fabric Apps - DAX Finance

Una aplicación de Fabric creada con la plantilla Data App de Rayfin y que se conecta a un modelo semántico de finanzas.

Sustituye el datagrid de la plantilla por uno hecho con [TanStack Table](https://tanstack.com/table/latest)
