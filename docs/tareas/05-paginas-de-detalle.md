# Tarea 05 — informe P&L

## Objetivo

Construir el informe P&L con una tabla propia en React y tarjetas resumen con datos reales del modelo semántico.

## Entregables

- Layout en `src/App.tsx`
- Tabla P&L con componentes propios basados en `@tanstack/react-table`: filas de cuenta/categoría, columnas de periodo, variaciones absolutas y porcentuales
- Tarjetas resumen superiores con importe, presupuesto y EBITDA del último año disponible
- Formato es-ES: moneda sin decimales con separador de miles, fechas en español

## Criterio de terminado

- El informe muestra datos reales del modelo P&L con formato correcto.
- La tabla y las tarjetas resumen se adaptan a light/dark mode con la identidad Dataxbi.
